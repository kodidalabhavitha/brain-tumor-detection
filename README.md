# Brain Tumor Detection Using CNN

## Overview

This project explores brain tumor detection and classification from MRI images using a Convolutional Neural Network (CNN). The deep learning model was developed to classify brain MRI images into four categories and evaluate the effectiveness of CNN-based image classification for medical imaging.

## Technologies Used

- Python
- TensorFlow
- Keras
- Convolutional Neural Networks (CNN)
- NumPy
- Matplotlib
- Image Processing
- Deep Learning

## Project Workflow

1. Collected and prepared brain MRI image data.
2. Preprocessed images for CNN model training.
3. Developed a Convolutional Neural Network for image classification.
4. Trained the model on brain MRI images.
5. Evaluated classification performance.
6. Analyzed model predictions and class-level results.

## Results

- Performed four-class brain MRI image classification.
- Achieved approximately 98% classification accuracy.
- Evaluated model performance across individual classes.
- Demonstrated the application of CNN-based deep learning to medical image classification.
